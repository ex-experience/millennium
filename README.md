# MILLENNIUM — Creative Agency / V2

Static editorial website designed for two deployment targets:

1. GitHub Pages: `https://ex-experience.github.io/millennium/`
2. Vercel: static deployment from repository root.

## Identity constraints implemented
- MILLENNIUM uses the supplied source raster. It is not re-typeset.
- No ™ is added to MILLENNIUM.
- Night field is the branch default.
- House lockup remains small and isolated.
- Door Blue is used as an agency field, not as a recolour of the house mark.
- Copper is used as a single controlled cut/hairline.

## Technical
- No framework/runtime dependency.
- Relative asset paths: GitHub Pages subpath safe.
- EN/AR and LTR/RTL.
- IntersectionObserver reveal/tone system.
- Native sticky editorial chapters.
- Horizontal cinematic work rail.
- Reduced-motion support.
- Accessible keyboard navigation and dialog.
- SEO / Open Graph / sitemap / robots.

Deploy by publishing the repository root.
