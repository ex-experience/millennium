# Source provenance

V3 was rebuilt from the browser/network capture of `https://island-light-orchid-scarlet.grok.me`. The original captured build contained 5 public routes and compiled Grok/React assets. `source-manifest.json` records every captured file with SHA-256. V3 does not reuse Grok runtime or its `Created with Grok` extension. It preserves public stills and the authoritative raster marks, and replaces the compiled UI with clean first-party HTML/CSS/JS.
