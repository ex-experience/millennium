What we do not use

This release has no user accounts, third-party analytics, advertising cookies or marketing cookies.

Message Room

When you choose Send Message, the information you entered — your name, email, message and optional attachment — is transmitted to a private server gateway and then into the MILLENNIUM project inbox. The receiving mailbox address is not exposed in the public interface.

Technical metadata

The gateway adds received time, a request identifier, page source and browser user-agent to the message for operational verification. The gateway code does not log the message body.

Attachments

An attachment passes in request memory to the email and is not stored as a persistent website file. The current limit is one file up to 2 MB.

Purpose

Messages are used only to read and respond to a contact or project enquiry. You may use the published Call or WhatsApp channels instead of the form.

External links

WhatsApp, Instagram and other external destinations apply their own privacy policies when opened.
